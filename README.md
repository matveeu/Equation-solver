# Equation solver

Программа для решения уравнений численными методами на языке C++.

## Возможности программы

- Решение уравнений методом бисекции (половинного деления)
- Решение уравнений методом хорд (секущих)
- Решение уравнений методом Ньютона (касательных)

## Как запустить?

### Компиляция:

```
g++ main.cpp -o solver
```

### Запуск программы:

```
./solver
```

## Методы решения

1. **Метод бисекции** - надежный, но медленный
2. **Метод хорд** - баланс надежности и скорости
3. **Метод Ньютона** - самый быстрый, но требует вычисления производной

## Поддерживаемые функции

- Линейные: kx+b = 0
- Квадратичные: ax²+bx+c = 0
- Обратные пропорциональности (гиперболы): k/x = b
- Синусы: sin x = b 
- Экспоненты: eˣ = b 
- Натуральные логарифмы: ln x = b
